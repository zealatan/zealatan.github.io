1. Conventions engine.js header

Bin ordering, normalization, determinism

FFT bins use natural order \(k=0..N-1\): \(k=0\) is DC, \(k\ge N/2\) are negative frequencies (\(f_k=k-N\)); the guard band straddles Nyquist. Both transforms are unitary (\(1/\sqrt N\) each direction), so Parseval holds exactly and per-bin noise variance equals per-sample noise variance — this is what makes the SNR definitions in §6 one-liners. All randomness (bits, noise, channel draws, phase noise) flows through one seeded generator (mulberry32 + Box–Muller): identical config + seed ⇒ identical samples (verified, Test G).

2. Bit source & Gray QAM Layer A

Mapping

Per axis, \(L=\sqrt M\) levels \(v_i=2i-(L-1)\) with Gray code \(g(i)=i\oplus(i\!\gg\!1)\), normalized to \(E_s=1\):

$$ c=\Big(2\cdot\tfrac1L\sum_i v_i^2\Big)^{-1/2},\qquad s=c\,(v_I+jv_Q),\qquad M\in\{4,16,64,256\} $$

Hard demapping slices each axis to the nearest level and re-emits the Gray bits — the exact inverse of the mapper (Test B: 0 errors for all four modulations).

3. Resource grid N=128, CP=16 default (configurable)

Active / pilot / data partition

Active bins = all \(k\in[1,N)\) except the guard band \(k\in[53,75]\) — the Nyquist bin \(k=64\) plus 11 bins on each side, 23 bins in total (the configuration value guard=22 sets the 11+11 side bins). DC (\(k=0\)) is nulled. Pilots take every 8th active bin plus the forced upper edge (14 pilots); the remaining 90 bins carry data. Pilot values are BPSK from an m-sequence LFSR (\(x_i=x_{i-3}\oplus x_{i-7}\)), independent of the data RNG and known to the receiver. Pilot and data sets are disjoint by construction.

4. OFDM modulation unitary IFFT + CP

Per-symbol synthesis

$$ x[n]=\frac{1}{\sqrt N}\sum_{k=0}^{N-1}X[k]\,e^{j2\pi kn/N},\qquad x_{cp}=\big[x[N-N_{cp}..N-1],\;x\big] $$

The forward FFT applies the matching \(1/\sqrt N\), so \(\mathrm{FFT}(\mathrm{IFFT}(X))=X\) to \(10^{-14}\) and energy is preserved (Test A). All symbols are serialized into one continuous IQ stream [P1, P2, data 0..13], each \(N_{cp}+N\) samples.

ifft() transmit() · signals ifftOut[sym], txIQ · view TX IQ

5. Preambles frame = [P1 | P2 | data…]

P1 — Schmidl & Cox symbol

Only even active bins are loaded (QPSK at power 2 from a dedicated fixed-seed RNG), so the time body consists of two identical halves of period \(N/2\) — the structure the S&C detector exploits.

P2 — fully known symbol

Every active bin carries the m-sequence BPSK value: the full \(N_{cp}+N\) waveform is known at the receiver and used for fine timing and integer-CFO resolution.

6. SNR definitions engine snrHelpers()

Three calibrated definitions

With unitary transforms and unit-power constellations, time-domain complex-noise variance \(\sigma^2\) equals per-bin variance, so:

$$ E_s/N_0 = -10\log_{10}\sigma^2,\qquad E_b/N_0 = E_s/N_0 - 10\log_{10}(\log_2 M) $$
$$ \mathrm{SNR}_{sample} = E_s/N_0 + 10\log_{10}\frac{N_{act}}{N} \quad\text{(data-symbol body: only } N_{act}\text{ of } N \text{ bins carry power)} $$

CP and pilot overheads are reported explicitly rather than silently folded in: \(10\log_{10}\frac{N+N_{cp}}{N}=0.51\) dB and \(10\log_{10}\frac{N_{act}}{N_{data}}=0.63\) dB for the defaults. In sample mode the noise power is calibrated against the measured frame power.

snrHelpers(), noise injection in applyChannel() · SNR slider + Es/N0 / Eb/N0 / sample selector · verified by Test D: QPSK empirical BER matches \(Q(\sqrt{2E_b/N_0})\) at 2–8 dB (e.g. 1.915×10⁻⁴ vs 1.909×10⁻⁴ over 2.1 M bits)

7. Multipath channel Layer B — real convolution, real ISI

Complex FIR

$$ y[n]=\sum_{\ell=0}^{L-1}h[\ell]\,x[n-\ell]+w[n] $$

Taps are drawn per realization: Rayleigh complex gains on the preset \(\{d_\ell,P_\ell\}\) profiles (EPA / EVA / ETU shapes at 20 Msps; Rician adds a K-factor LOS to tap 0), normalized to \(\sum|h|^2=1\). The convolution runs over the whole frame — when the excess delay exceeds the CP (ETU's 100-sample tap vs CP = 16), inter-symbol interference genuinely appears and no per-subcarrier equalizer can remove it (Test E: 9.1×10⁻² vs 6.3×10⁻⁴ within-CP). Nothing multiplies QAM symbols by random per-symbol coefficients.

8. RF impairments fixed, documented ordering

Order: PA → FIR → CFO → phase noise → SFO → AWGN → IQ → DC

$$ \text{CFO: } y[n]\leftarrow y[n]e^{j2\pi\epsilon n/N} \;\;(\text{continuous } n \text{ across the frame}) $$
$$ \text{PN: } \phi_{n+1}=\phi_n+w_n,\; w_n\sim\mathcal N(0,\,2\pi\beta/F_s) \qquad \text{PA: } G(|x|)=\big(1+(|x|/A)^{2p}\big)^{-1/(2p)} $$
$$ \text{SFO: } y[k]=x\big(k(1+\delta)\big)\ \text{via linear interpolation} \qquad \text{IQ: } Q'=g(\sin\varphi\, I+\cos\varphi\, Q),\ I'=I \qquad \text{DC: } y\leftarrow y+dc $$
$$ \text{PA (output back-off } B \text{ relative to the measured mean power } P_{avg}\text{ of the frame):}\quad A=\sqrt{P_{avg}}\,10^{B/20} $$

SFO is an actual resampling of the sample stream (linear interpolation — limitation: first-order kernel), not a constellation rotation. PA acts at the TX; AWGN, IQ imbalance and DC are receiver-side. A constant DC offset lands only on FFT bin 0, which is a null, so it does not change data-bin EVM (Test F). The AWGN preset is \(h=[1]\) (no fading and no phase); the fading presets are Rayleigh/Rician realizations. Every impairment is validated against its own signal-domain property in Test F and in tests/test_verify.mjs, section F.

9. Synchronization practical vs oracle (labeled)

Stage 1 — Schmidl & Cox on P1

$$ P(d)=\sum_{n=0}^{N/2-1} r^*[d+n]\,r[d+n+N/2],\qquad M(d)=\frac{|P(d)|^2}{R_1(d)R_2(d)}\le 1 $$
$$ \hat\epsilon_{frac}=\frac{\angle P(d_{max})}{\pi}\in(-1,1) \ \text{subcarriers} $$

Normalizing by BOTH half-window energies (Cauchy–Schwarz bound) plus an energy gate kills the 0/0 false peaks that plague the classic \(|P|^2/R^2\) form in silent regions — a real bug found and fixed by Test C.

Stage 2 — known-P2 cross-correlation with integer-CFO hypotheses

$$ (\hat k,\hat d)=\arg\max_{k\in[-K,K],\,d} \Big|\sum_n p_2^*[n]\,r_k[d+n]\Big|,\qquad r_k = r\,e^{-j2\pi(\hat\epsilon_{frac}+k)n/N} $$

First-path refinement walks back from the argmax (≤ one CP) to the earliest lag above 50% of the peak, then a 2-sample backoff into the CP guards against locking late on a strong tap; the resulting known linear phase is absorbed by channel estimation (§10). Oracle mode instead hands the receiver the true delay and CFO from the channel metadata — always labeled in the UI, used for baselines (Tests D/E).

10. Channel estimation on the actual received pilots

LS + delay-compensated linear interpolation (default)

$$ \hat H_p[i]=\frac{Y[k_i]}{X_p[k_i]},\qquad \hat\psi=\frac{1}{\Delta k}\angle\sum_i \hat H_p[i\!+\!1]\hat H_p^*[i] $$

A timing offset \(\tau\) makes \(H[k]\) spiral as \(e^{j2\pi k\tau/N}\); linearly interpolating that spiral between pilots is badly biased. So the dominant per-bin phase slope \(\hat\psi\) is estimated from adjacent-pilot products (pilots only — no oracle), the pilots are derotated, the slowly-varying residual is linearly interpolated, and the ramp is re-applied. This is what lets the deliberate sync backoff cost nothing (Test C: EVM 10⁻¹³ with a −2-sample offset).

Alternatives

perfect — oracle: \(H_s[k]=\sum_\ell h[\ell]e^{-j2\pi k\ell/N}\cdot e^{j2\pi k\tau/N}\cdot e^{j2\pi(\epsilon_{true}-\hat\epsilon)(n_s+\tfrac{N-1}{2})/N}\), with the receiver's actual window offset \(\tau\), the residual CFO \(\epsilon_{true}-\hat\epsilon\) taken at the window centre of symbol \(s\) (\(n_s\) = window start). This makes the oracle valid when practical sync is used (Test G4: 0 errors, same as oracle sync). ls-dft — pilot-axis IDFT, keep the CP-supported taps, DFT back (band-limited smoothing; the pilot axis spans only the active band, noted limitation). lmmse — ls-dft with per-tap Wiener weights \(p_\ell/(p_\ell+\sigma^2/P)\), prior \(p_\ell\propto e^{-0.5\ell}\) (normalized; this is an assumed PDP, not the channel's own profile), genie \(\sigma^2\) (labeled).

11. Equalization per subcarrier

ZF and MMSE with fade protection

$$ \hat X_{ZF}=\frac{Y\,\hat H^*}{\max(|\hat H|^2,10^{-12})},\qquad \hat X_{MMSE}=\frac{Y\,\hat H^*}{|\hat H|^2+\sigma^2} $$

On frequency-selective realizations, ZF noise enhancement on deep-faded bins is real physics. Test E checks the measured BER against the per-bin Rayleigh theory with oracle CSI (3/8·erfc√(γ_k/10), \(\gamma_k=|H_k|^2/\sigma^2\)) within 3 SE; the ZF noise-enhancement law \(\mathrm{EVM}^2=\mathrm{mean}_k\,\sigma^2/|H_k|^2\) is checked at 60 dB in Test H2 (measured/predicted = 1.003).
